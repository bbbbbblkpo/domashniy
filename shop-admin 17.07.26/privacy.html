Какие данные и зачем

Сервис используется для внутреннего учета магазина. Он обрабатывает учетные записи (логин и хэш пароля), имена работников, смены, начисления зарплаты, авансы/долги, а также сведения о заказах поставщикам. Данные используются только для учета работы магазина, авторизации, защиты доступа, аудита и резервного копирования. Не добавляйте в комментарии данные, не нужные для этих целей.
